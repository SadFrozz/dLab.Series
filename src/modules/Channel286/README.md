# dLab 286

The 286 processor inside dLab.Series. Build from the [repository root](../../../README.md).

Project One and 286S share the parameter layout while selecting circuit behavior and panel theme. LINE gain ranges are -5 to +45 dB (Project One) and -15 to +45 dB (286S). The path includes input gain/HPF, Drive/Density compression, de-essing, LF/HF Detail, expansion/gating and output gain. Process bypass preserves the input path. Guide choices highlight ranges without loading presets.

Permanent identity C286, parameter IDs and Channel286State are preserved. The root suite selects the current DSP and plugin checks. Source documents and historical calibration scripts are not needed to build them.
