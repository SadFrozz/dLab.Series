# dLab 376

The 376 processor inside dLab.Series. Build from the [repository root](../../../README.md).

Current approved choices are Warm, Bright and Muted clean tonal profiles, rather than manufacturer-specific tube models or generated saturation harmonics. The remaining path includes EQ with clipping indication, OverEasy compression with FAST/SLOW, de-essing and output gain.

Supports mono/stereo and float32/float64. Optional oversampling (Off/2x/4x) is Off by default. Output remains PCM; dithering/noise shaping belongs to the DAW. No standalone product is included. Permanent identity C376, parameter IDs and Channel376State are preserved. Historical tube and digital-output research is not the current product specification; current regression tests are selected by the root suite.
